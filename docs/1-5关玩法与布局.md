# 1–5 关玩法与布局

更新：2026-09-22。本文对应 `src/game/levels/level01.ts` 至 `level05.ts` 和 `layout.ts` 的当前实现；替代旧版 24×20 房间规格。关卡 / 前端 / 测试维护者共同维护。

后续手感、碎裂悬台、难度窗口和寒气/热汽表达见 [操作手感与机关反馈](./操作手感与机关反馈.md)。

## 参考与取舍

参考 [Coolmath Games：Fireboy and Watergirl in the Forest Temple](https://www.coolmathgames.com/0-fireboy-and-water-girl-in-the-forest-temple) 的公开玩法说明（2026-09-22 查阅）：同屏观察迷宫、分色收集、元素互斥、双角色开关接力、先规划后行动。原作绿池同时伤害双方；本项目没有实现绿池，不能把冰雾误当作双方致命区域。

本次借鉴的是“看得清全局、不同高度都有任务、互相接应”的结构，不复制原作地图、角色或素材。保留本项目写实角色、残烬诱敌、潮位、救援及蒸汽机制。未生成新位图，继续使用项目已有美术。

## 比例、碰撞与视图

- 房间：24×14 格，48px/格，即 1152×672 世界像素，整房间适配，无滚屏。
- 主路线地面：阁楼 y=2.8 格，火侧主廊 y=5.6 格，水侧底道 y=13.3 格。新增阶梯连接必要符文和可选晶石，不再把整条不可达长台当作“层数”。
- 角色：22×34px 碰撞体，精灵高 50 世界像素，脚底锚点与碰撞脚底一致；头发/披风允许超出碰撞体。相比旧 16px 碰撞宽 / 44px 精灵高更清楚。
- 满跳理论抬升 108px（2.25 格），阶梯抬升以 1.4 格为主，新增阶梯平台厚 14px；高处折返需要留出角色宽度，不要求像素级落脚。
- 平台贴图不再向碰撞顶面上方扩张 28px；顶边亮线直接标识落脚面；终点压板绘制完整宽度的受压条，中央图标缩小后仍能识别实际有效区域。水和熔岩贴图也不再向危险区上方大幅延伸。
- 背景等比 cover，不拉伸；远景 / 中景透明度为 0.48 / 0.18。移除盖在路线上的装饰竖柱。
- 相机以游戏舞台的实际 CSS 宽高 fit，删除移动端至少 640×360 的虚拟尺寸限制。HUD 在舞台外，不覆盖出生点、阁楼或出口。

## 收集与出口规则

每关 6 件收集物：烬 3 件、朔 3 件，其中每人各 1 枚带外框的**必需符文**，另外 4 枚为普通晶石。只能由对应颜色且未倒地的角色接触拾取，同一 ID 只计一次。

1. 双符文未齐，机关条件即使满足也不能开出口。
2. 第 1 / 4 / 5 关：双符文 + 双压板保持 0.8s。
3. 第 2 关：双符文 + 深潮位沉箱压井；开门保持 8s。
4. 第 3 关：双符文 + 油桥烧塌 + 双压板保持 0.8s，防止直接走桥绕过点燃机制。
5. 出口门已开且双人分别进入同色出口，保持 0.5s 后通关。
6. 普通晶石不是通关门槛；三星必须收齐全部 6 件，同时零死亡、未用电荷、时间不超过本关目标。重开清空本局收集，不修改旧存档的历史最高星级。

## 各关路线

| 关卡 | 空间组织 | 玩法顺序 / 支路 |
|---|---|---|
| 01 裂隙初醒 | 火侧阁楼跨隙落入主廊；水侧左侧三段折返梯、悬台支路、底道熔岩坑 | 烬取阁楼符文并引残烬；朔攀梯取符文，可跳到悬台取额外晶石；返回底道后由烬压板接应，等待蒸汽安全窗，双板开门 |
| 02 潮汐石阶 | 火侧高廊拨杆与断口；水侧先向右上升再折回左侧悬台、配重井与浮冰 | 先完成收集再推箱到井边，烬拨深潮沉箱开闩，再降到中潮并去接应压板；朔过门后两人去出口 |
| 03 焦木栈道 | 烬新增阁楼折返和跨井踏台；朔为向右上升的阶梯，右侧可选悬台踩上 0.9s 坍塌 | 双人取符文；可选悬台取晶后及时跳回；朔先越木桥，烬从高踏台跨井到油桥上方按 J；等待烧塌形成灰烬，再压板接应、双板开门 |
| 04 双闸回廊 | 火侧阁楼折返；水侧 1.6 格抬升梯、左侧 0.65s 碎裂悬台与宽落井，接反相内环和蒸汽终段 | 烬先引残烬；朔取符文后返回底道，通过初始开启的水闸，踩内环冰板切换；烬通过熔岩闸后接应朔穿过蒸汽，再一起开门 |
| 05 沉钟齿轮 | 火侧上层拨杆、下层接应台；水侧可选折返支路、中室符文台和两段时序门 | 烬取阁楼符文后启动；朔穿首闸，在中室 y=11.7 格石台取必需冰符文，再穿末闸。火闸 0–2.2s 开，水侧第一闸 1.4–2.8s 开，末闸 3.6–6.4s 开；每 10s 循环，错过可等下一轮 |

阶梯精确坐标由 `branchLayout()` 给出；五关均为独立轮廓，不是同一折返梯的水平平移。第四关左悬台与符文台之间留有 1.1 格宽下落口（角色宽约 0.46 格）；第五关左侧支路仅放可选晶石，必需冰符文位于两扇时序门之间。所有按住门及第四关水相闸上缘为 y=5.6 格；第五关水侧齿轮门上缘 y=5.95 格，不能从收集高台跳过关闭的机关。

## UI 与状态反馈

- 选关使用真实关卡数据生成 SVG 缩略图，并展示关号、关名、玩法主题、解锁/星级和流程。
- 顶栏：返回、暂停/继续、重开、可收起的提示；标题、计时、死亡、晶石总数。
- 选关标明挑战序号与三星目标时间；普通通关不受目标时间强制终止。第三/四关碎台在缩略图中以虚线描边区分。
- 目标栏：双符文计数、随模拟状态变化的下一步目标、出口状态。第五关先提示启动，再提示中室取符文，不会让玩家在未开闸时寻找不可达符文；第二关深水开门后先提示降潮。场内必需符文有外框，普通晶石无外框；出口使用暖 / 冷色并配不同符号。
- 底栏：两套键位、各角色 0/3 收集计数、元素安全/危险说明、机关当前状态。宽屏显示蒸汽安全/预示/喷发剩余时间、油桥烧塌倒计时、相位锁定时间，或下一扇尚未通过的齿轮门开关时间。计时读取模拟钟，暂停时不会自行流逝；窄屏保留目标和个人计数，收起详细机关状态以免挤占舞台。
- 通关可以进入下一关，第五关不显示不存在的“下一关”。小屏完整 fit 并提示横屏 / 键盘，不伪装成支持触屏控制。
- 浏览器失焦/切后台自动暂停并清空按键，恢复须主动继续。救援中暂停不会重置救援剩余时间。
- 按住门与已启动的齿轮门在门洞有角色/箱子时延迟闭合，避免关门嵌入碰撞体。
- `prefers-reduced-motion` 冻结非必要水面流动、装饰闪动；物理钟、蒸汽危险相位和角色移动不改变。
- 寒气区取消漂浮白雾，以边框/霜纹/雪花及“寒气 · 烬禁入”表达范围；热汽由地面金属喷口发出，三个阶段有文字与压力格数。粒子不越出实际危险区。此类少量玩法标识优先于旧美术目标中“场内不使用文字”的约定。

## 验收与已知边界

- 5 关均有从真实出生点开始、只输出按键意图的全收集 / 零死亡 / 不消耗电荷 / 三星回放。没有在回放中改坐标、开门或补收集物。
- 几何、配色拾取、门禁、烧桥前置、齿轮循环、防夹、评分和小屏相机见 `tests/room-layout.test.ts`；其他原有伤害与机关测试继续保留。
- 浏览器的交互、响应式与验证限制见 [测试文档](./测试文档.md)。自动回放证明存在解法，不代表真人平均游玩时长或难度评分。
- 当前未提供移动触屏双人输入、检查点、联机、6–18 关；音量 / 粒子设置字段不代表已有设置界面。

## 界面色板

当前仅暗色主题，无浅色切换。HUD 使用 `styles.css` 的变量；游戏元素保留已有暖火 / 冷水配色，状态同时使用边框、图形与文字，不只靠色相。
