# 业务说明

## 1. 产品目标

让两名玩家（或一名玩家的两只手）在写实神殿废墟里完成高信息量协作：谁碰什么、谁先动、谁等待、谁诱敌，都必须想清楚。不是跑酷高分，也不是开关博物馆。

## 2. 术语

| 术语 | 含义 |
|---|---|
| 烬 | 焰行者，火侧角色 |
| 朔 | 霜行者，冰侧角色 |
| 圣所 | 关卡世界「林渊圣所」 |
| 伤害场 | 持续判定的元素区域（熔岩、深水、蒸汽等） |
| 材料 | 可被点燃、融化、承重、导电的可破坏/可逆物体 |
| 闩锁门 | 条件满足后保持开启一段物理时间，即使玩家离开压板 |
| 寻热残烬 | 追踪最近角色的慢速敌意体，可被烬安全吸引 |
| 失联 | 两人距离超过 28 格时的惩罚与提示，不是失败 |
| 复苏祭坛 | 救援倒地同伴的交互物，消耗电荷 |
| 电荷 | 本关有限资源，救援与部分支路共用 |
| 三星 | 时间 / 死亡 / 未消耗电荷（含未救援） |

## 3. 角色与能力

无账号。权限只有「本地玩家」。两角色必须都到达本关终点槽才能通关。

### 3.1 焰行者「烬」

- 安全：熔岩浅层、明火、高温金属、寻热残烬接触
- 致死：深水、冰雾池、冷凝液体、冻雨核心
- 技能：点燃燃料（短距交互）、融化薄冰桥、激活火符文
- 体感：质量较低，跳略高，落地滑步短；可被弱上升气流托起
- 刻画：深赤多层袍、发梢暗燃、琥珀虹膜、熔岩中脚底气泡；湿润状态头发贴服、火焰熄灭（视觉警告：即将对水更敏感的表现，不改变已有伤害表）

### 3.2 霜行者「朔」

- 安全：深水、冰面、冷凝机关、冻雨
- 致死：熔岩、明火核心、过热蒸汽、被点燃的木质坍塌区
- 技能：冻结浅水成临时立足点（有寿命）、熄灭弱火、激活冰符文、短距冰壁滑降
- 体感：更沉，冰面摩擦极低，必须预刹；气流默认托不起，除非卸负或灌了反向
- 刻画：青灰结霜披风、发丝冰棱、呼气白雾；灼烧余烬状态布料焦边（视觉警告）

两人不能互换终点槽：烬的终点是干热壁龛，朔的是冷凝壁龛。走错会持续轻伤并被推回。

## 4. 核心流程

1. 封面 → 操作说明（可跳过但第 1 关内仍有环境提示，无幼儿园箭头长廊）
2. 选关：未解锁关不可进；通关解锁下一关
3. 进入关卡：两人从各自出生点出现，计时开始
4. 探索、协作、失败重开或通关结算
5. 三星写入存档；可重打刷星

## 5. 业务规则

### 5.1 元素伤害（阶段 B 必须测死）

| 场 | 烬 | 朔 |
|---|---|---|
| 浅熔岩 | 安全，减速 10% | 立即倒地 |
| 深熔岩 | 安全，减速 20% | 立即倒地 |
| 浅水 | 倒地 | 安全 |
| 深水 | 倒地 | 安全，可潜 2 格 |
| 过热蒸汽 | 安全 | 倒地 |
| 冰雾池 | 倒地 | 安全 |
| 酸雾 | 双方倒地 | 双方倒地 |
| 寻热残烬接触 | 安全 | 倒地 |

倒地前若该帧已在救援无敌（刚复活 1.2s）则忽略。

### 5.2 协作

- 默认键位：烬 WASD + J 交互/技能；朔 方向键 + 小键盘 0 或 `;` 交互/技能（可重绑）
- 跳跃支持 80ms 土狼时间与 100ms 落地前缓冲；轻点为短跳、按住为高跳，持续按住不会在落地后自动再次起跳
- 禁止系统代打另一人通过终点
- 「焦点切换待机」可作为辅助：**待机角色保持当前平台，不自动跳、不自动按压板**；通关仍要两人进槽

### 5.3 机关原则

每个机关状态必须能从场景读出：齿轮是否咬合看齿间木屑，熔岩闸看沟槽辉光，假开关看无油污/无霜。

禁止隐形伤害。周期机关至少 0.35s 预示（发光、振动、粒子转向）。

### 5.4 评分

- 3 星：通关时间 ≤ 目标上限，且死亡 0，且电荷未消耗
- 2 星：通关且死亡 ≤ 关卡允许值，或只用了电荷但时间合格
- 1 星：通关
- 第 1 关目标时间 240s，允许死亡 6 次仍得 2 星；0 死 + 不用祭坛 + ≤240s 才 3 星
- 第 1 关预期正经玩家 2–4 分钟、死亡 2–6 次

### 5.5 检查点

- 1–8 关：无
- 9–12：至多 1
- 13–18：至多 2，且检查点不能跳过本关核心协作节拍

## 6. 状态变化

关卡实例：`loading → playing → paused → playing`；`playing → rescue_window → playing|failed`；`playing → cleared`。

角色：`idle/walk/run/jump/fall/land/push/pull/interact/hurt/downed/revive`。

门：`closed → opening → open → closing → closed`；闩锁门在 `open` 持有 `latchMs`。

压板只在角色双脚落地且脚底中心进入有效面时受压；侧面擦碰或空中掠过不算踩下。

按住门（`holdGates`）：石门默认挡住对应分路。指定角色必须站在压板上，同伴才能通过；离板门立刻落下。与终点双压板闩不同——终点闩是踩满 0.8s 后保持 5s，按住门没有保持时间。

## 7. 异常处理

| 情况 | 处理 |
|---|---|
| 一人掉出世界包围盒 | 视为倒地（`actor.y` 超过关高 +1 格） |
| 箱子落入无交互熔岩深坑 | 4s 后提示软锁，不偷改局面 |
| 同时踩双锁但窗口错开 | 门不开，提供咬合失败音，不弹提示文字剧透 |
| 存档版本落后 | 迁移函数；不可迁移则备份并重置进度，设置保留 |

## 8. 边界

- 最小通关单位是「一关」，不能只送一人进终点
- 浅水冻结立足点最多存在 3.5s，同时最多 3 块，防止铺路跳过整关
- 点燃木质结构不可逆（第 14 关连锁依赖此点）
- 换位术（第 16 关）交换位置并给双方 1.5s 元素污染：烬短暂怕热、朔短暂怕水，防止换位当飞行
