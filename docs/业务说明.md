# 业务说明

更新：2026-09-24。本文仅描述当前实现；关卡 / 产品 / 实现维护者在玩法变化时同步维护。逐关路线见 [1–5 关玩法与布局](./1-5关玩法与布局.md)，未来关卡见 [关卡设计](./关卡设计.md)。

## 产品范围与角色

浏览器同机双人协作平台解谜，无账号、联机或服务器排行榜。可由两名玩家分键位操作，也可单人控制两人；没有自动替玩家通关的 UI。

- 烬：WASD（W 跳跃）+ J 交互；安全通过熔岩、冰雾致命、碰水倒地，可安全吸引寻热残烬。
- 朔：方向键（↑ 跳跃）+ 分号交互；安全通过水、熔岩与过热蒸汽致命，接触残烬倒地。
- 双方跳跃参数相同，烬普通地面/空中最高水平速度 240px/s、朔 232px/s，支持约 80ms 柔和起步和短距离刹停。S / ↓ 为 50% 目标速度的精准慢行（120 / 116px/s），未实现蹲下、滑降或潜水。冰面仍保留 1.18 倍速度上限与滑行。细节见 [操作手感与机关反馈](./操作手感与机关反馈.md)。
- 交互支持拨杆和祭坛；J 也能点燃满足范围条件的油桥。冻结浅水、熄火、换位、气流等属于规划，不是已实现技能。

## 用户流程

封面 → 说明或选关 → 进入已解锁关 → 探索 / 收集 / 协作 → 双人到达对应出口 → 结算、下一关或重玩。

选关当前只展示 1–5 关，未解锁关不可点。每关缩略图来自真实地形。通关写入 localStorage，提高解锁数量，保存最高星数和最短用时；不会降低旧版本存档的历史成绩。第 5 关没有“下一关”按钮。

HUD 提供返回、暂停、重开和折叠提示。Esc 暂停 / 继续；游玩中长按 R 0.4s 重开，暂停或结算时点按 R 立即重开。失焦或切后台会暂停并清空按键；暂停后的救援窗保留原剩余时间。

## 收集、机关与通关

每关 6 件同色收集物，其中两枚带框符文必需，四枚普通晶石为可选收集。异色角色不拾取，倒地角色不拾取；重开全部复原。

- 双符文是所有出口机关的共同前置。
- 第 1 / 4 / 5 关双压板同踩 0.8s 开闩，保持 5s。
- 第 2 关需深潮位下箱子压井，开闩保持 8s；潮位拨杆走入即触发，也可按交互切换，顺序浅 → 深 → 中 → 浅。
- 第 3 关需油桥烧塌后双压板同踩，烧桥不可逆，重开恢复。
- 第 3 / 4 关可选晶石悬台踩上后分别在 0.9 / 0.65s 坍塌，2.2s 后恢复，恢复区域有角色/箱子时继续等待；不是永久断路。
- 第 4 关内环压板切换反相闸，有 3s 相位锁定时间；保持踩住不重复切换，必须离板才能重新触发。
- 第 5 关齿轮启动后 10s 循环；火闸 0–2.2s、首闸 1.4–2.8s、末闸 3.6–6.4s 开启。错过可等下一轮，再次交互拨杆可从周期起点开始。
- 同色出口不可互换。必须出口门开启、符文齐全、两名未倒地角色分别在对应出口重叠 0.5s 才通关。

按住门的指定角色必须落地、脚底中心在板内才能开门，侧擦/空中经过不算。离板后关门，若门洞有角色或箱子则等待离开。已启动的齿轮门同样防夹；终点闩门已有角色占门延迟关闭规则。

## 伤害、失败与救援

| 场景 | 烬 | 朔 |
|---|---|---|
| 浅/深熔岩 | 安全，减速 10% | 倒地 |
| 浅/深水、冰雾 | 倒地 | 安全 |
| 蒸汽安全/预示期 | 安全 | 安全 |
| 蒸汽喷发期 | 安全 | 倒地 |
| 寻热残烬接触 | 安全 | 倒地 |
| 越过世界底边一格 | 倒地 | 倒地 |

蒸汽周期为安全 1.4s、预示 0.4s、致命 1s。单人倒地进入 8s 救援窗；另一人在祭坛区域按交互，消耗本关 1 次电荷，倒地者原地复活并无敌 1.2s。双方倒地或救援超时失败。没有检查点。

跳跃支持 100ms 土狼时间、120ms 提前输入缓冲、松键短跳；一直按住不会落地自动连跳。满跳高度不变，平地满跳滞空约 0.75s，下降重力为上升的 1.08 倍。跑步/待机动作放缓，落地恢复为 160ms 的视觉反馈，不锁输入；机关计时和箱子下落不随人物一起慢放。

闸门宽度统一收窄至 24px，视觉与碰撞同步调整，中心位置及防绕关高度不变。门扇在原框内开合，不伸入相邻楼层；原有开门前置、时序窗口和各类门防夹规则不变。跳跃顶点保持同帧，下落不播放蜷缩末帧，连跳不叠加上一跳的落地压缩；均不改变跳高、跳距或输入响应。

寒气区显示冷蓝边框、雪花和“烬禁入”，不是可站立的实体平台；地面热汽喷口显示“冷却 / 蓄压 / 喷发”，粒子不越出伤害区域。此轮只改表达，不改变伤害矩阵。倒地角色不能操作拨杆或点燃机关。

## 评分

- 三星：收齐本关 6 件收集物、零死亡、未用电荷、时间不超过本关目标。
- 二星：已通关，死亡数不超过本关阈值；无需全收集。
- 一星：其余已通关情况。
- 1–5 关时间阈值分别为 120 / 110 / 100 / 90 / 80 秒，二星死亡上限 6 / 5 / 5 / 5 / 4；超时不结束本局，仍可通关。

## 状态与限制

实例状态：playing、paused、rescue_window、failed、cleared。React 的加载失败页面独立于模拟状态。重开清除本局时间、死亡、机关、收集物和按住重开进度。

当前仅 1–5 关实现；6–18 关、检查点、绿池、键位重绑 UI、存档导入导出、音效系统、触屏控制仍未实现。localStorage 缺失、JSON 损坏或版本不匹配会使用默认档；没有已实现的坏档备份和完整 schema 校验，亦不能保证浏览器禁止写入时正常保存。
