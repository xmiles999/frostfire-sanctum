## 阶段 B 范围（确认后）

只做能证明手感与难度的一条竖切：

1. Vite + React 壳：封面 → 进入第 1 关 → 暂停/重开
2. Pixi 画布：4 层视差、风格化写实第 1 关场景切片
3. 固定时间步：移动、跳跃、落地、元素伤害
4. 双键位同时控制
5. 第 1 关三个节拍全部可解、可失败、可重开
6. 单元测试：伤害矩阵、双压板闩锁、残烬寻热

## 风险

| 风险 | 缓解 |
|---|---|
| 写实素材量太大 | 第 1 关先做完整角色循环 + 本关场景；其余关复用材质套件换光与布局 |
| 平台跳跃不公平 | 跳跃高度、土狼时间、缓冲写入常量；禁止唯一解依赖亚像素 |
| 双人相机晕动 | 约束框死区 + 最大分离 28 格；超距只警告不传送通关 |
| 第 1 关过难劝退 | 可读性优先于伤害；每个致死点有 0.35s+ 预示；不降低规则复杂度 |
