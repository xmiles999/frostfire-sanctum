# 开发文档

## 1. 环境

- Node.js 20.19+（镜像内 22）
- npm 10+
- 现代桌面浏览器（Chromium 内核优先）
- 可选：Docker 24+（构建与 Dokploy 一致）

已锁定：Node 20.19+、`package-lock.json`。依赖见根目录 `package.json`。

## 2. 目录结构（目标）

```
frostfire-sanctum/
  docs/                 中文文档（已有）
  src/
    ui/                 React 页面
    game/
      engine/           循环、输入、物理、相机
      actors/           角色与动画状态机
      world/            材质、液体、伤害
      systems/          机关、救援、评分
      levels/           schema + 加载器
  public/
    assets/             角色、场景、UI、音频
    levels/             18 份关卡 JSON
  scripts/              dev.sh / start.sh / lib.sh
  deploy/               dokploy-compose.yaml
  Dockerfile
  Caddyfile
  index.html
  package.json
```

阶段 B 已有 `src/game/**` 模拟层、`src/game/view/GameView.ts`、`src/ui/App.tsx`、`tests/**`。

## 3. 依赖安装

```bash
cd /data/projects/frostfire-sanctum
npm install
```

拟定依赖：`react`、`react-dom`、`pixi.js`、`zod`。  
拟定开发依赖：`typescript`、`vite`、`@vitejs/plugin-react-swc`、`vitest`、`eslint`。

## 4. 命令（阶段 B 起）

| 入口 | 用途 | 停止 | 健康 |
|---|---|---|---|
| `./scripts/dev.sh` | 依赖检查后 Vite dev，默认 5173 | Ctrl+C | 打开页面 |
| `./scripts/start.sh` | `npm run build` 后 preview，默认 4173 | Ctrl+C | 打开页面 |
| `npm run test` | vitest | 进程结束 | 退出码 0 |
| `npm run build` | `tsc` + `vite build` | — | 产出 `dist/` |
| Docker | 见 [部署运维.md](./部署运维.md) | 停容器 | `GET /healthz` |

环境变量：`PORT`、`HOST`。缺 `package.json` 或 Node 版本不足必须非 0 退出。端口占用必须明确报错，不改打其他端口（除非调用者改 `PORT`）。

脚本行为对齐 `image-convert-ocr/scripts`：`set -euo pipefail`、日志进 `.logs/`、不静默忽略错误。

脚本已写入。按仓库偏好，未在本机代为启动 Vite；需要试玩时再执行 `./scripts/dev.sh`。

## 5. 配置入口

| 文件 | 内容 |
|---|---|
| `vite.config.ts` | 别名 `@game` `@ui`，静态 `public/` |
| `src/game/engine/constants.ts` | 重力、速度、土狼时间、最大分离 |
| `src/game/levels/catalog.ts` | 第 1–5 关入口 |
| `public/levels/*.json` | 关卡数据 |
| 浏览器 localStorage 键 `frostfire.sanctum.v1` | 存档 |

无必填环境变量。生产 `SITE_URL` 仅用于文档/OG，不影响玩法。

## 6. 调试

- 开发模式：F1 开关碰撞盒、机关图、当前物理帧
- 伤害场半透明叠加
- `?level=01&god=0` 深链进关；禁止默认开无敌
- 逻辑测试不启动 Vite、不启动 Pixi
- 第 1 关走路/路面再导出：先把视频采到 `.scratch/ember-walk` 与 `frost-walk`，再 `python3 scripts/process-level01-art.py`
- 只重导岩浆/河流贴图：`python3 scripts/process-level01-art.py --liquids-only`

## 7. 关卡作者工作流

1. 在 [关卡设计.md](./关卡设计.md) 改规格
2. 按 [数据模型.md](./数据模型.md) 写/改 JSON
3. 跑该关官方解法测试
4. 走查难度：若 30 秒无脑过，加信息约束或缩短窗口，不加血

## 8. 常见问题

**问：为什么不用 Phaser？**  
渲染可以，但 Arcade 物理承担不了液体、单向台与精确窗口。避免两套真相。

**问：角色可以先用方块吗？**  
第 1 关竖切不允许以方块人为完成定义。可用低分辨率写实草稿，但必须是绘制角色并带状态差。

**问：能否先做 18 张空地图？**  
不能。先第 1 关竖切，再按规则引入表扩系统，再量产。
