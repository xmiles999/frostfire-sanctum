# 开发文档

更新：2026-09-23。开发者维护命令、配置与测试边界；架构见 [设计文档](./设计文档.md)，业务见 [业务说明](./业务说明.md)。

## 环境和依赖

`package.json` 要求 Node.js ≥20.19.0，使用 npm 和已提交的 `package-lock.json`。本次验证使用 Node 22.23.1。安装：`npm ci`。当前技术为 React 19、TypeScript 5、Vite 6、PixiJS 8、Vitest 3；精确版本以锁文件为准。zod 虽已安装，当前关卡加载没有运行 schema 校验。

## 启动、停止和健康检查

| 命令 | 行为 | 停止 / 验证 |
|---|---|---|
| `./scripts/dev.sh` | 检查 Node、依赖与端口后启动 Vite；默认 5173 | Ctrl+C；根路径 HTTP 200、选关和游戏可进入 |
| `PORT=5175 HOST=127.0.0.1 ./scripts/dev.sh` | 指定本地空闲端口和绑定地址 | 同上 |
| `./scripts/start.sh` | 构建并启动 preview，默认 4173 | Ctrl+C；根路径 HTTP 200 |
| `npm run build` | TypeScript 检查后打包到 `dist/` | 退出 0；不能代替浏览器验证 |
| `npm test` | Vitest 逻辑、布局和回放测试 | 自动退出 |
| `npm run test:watch` | 持续运行 Vitest | Ctrl+C |

日志位于 `.logs/dev.log`、`.logs/preview.log`（以脚本实际输出为准）。重复执行启动脚本遇到占用端口会明确失败，不改用随机端口，不结束其他项目进程。无需必填配置文件或密钥。`HOST` 默认为 `0.0.0.0`，本机验证建议明确设为 `127.0.0.1`。

若环境的 `/tmp` 不可写，可为测试命令显式指定已存在且当前用户可写的 `TMPDIR`；不要更改系统目录权限。本次 `/tmp` 和 `/data/tmp` 均不可新建目录，临时使用仓库外的用户可写目录进行 QA，未修改主机权限。

启动脚本本次未修改。本次实际启动 5175 成功；部署与生产 `/healthz` 见 [部署运维](./部署运维.md)，Vite 开发服务器不等价于 Caddy 的生产健康检查。

## 真实入口与目录

- `src/main.tsx` / `src/ui/App.tsx`：React 页面状态、选关、HUD、键盘监听和 Pixi 生命周期。
- `src/ui/LevelPreview.tsx`：从关卡数据生成选关缩略图。
- `src/game/runtime.ts`：requestAnimationFrame、固定 1/120s 模拟步、最多 8 步追帧、10Hz HUD 通知、存档结算。
- `src/game/sim/{types,create,step,world}.ts`：数据契约、初始状态、机制更新、当前碰撞体/危险区。
- `src/game/sim/{animation,fragile,interactions,guidance}.ts`：动作时钟、碎裂踏台、交互范围/提示/确认、关卡任务指引。
- `src/game/engine/`：物理、相机、输入、矩形和常量。
- `src/game/levels/catalog.ts`：实际 1–5 关目录。`level01.ts` 至 `level05.ts` 为运行数据；`layout.ts` 负责紧凑纵向坐标、收集支路与 UI 主题文案。
- `src/game/view/GameView.ts`：精灵加载、平台/机关/收集物渲染；渲染不决定碰撞。
- `src/game/view/{actorPose,hazardVisuals}.ts`：纯动作姿态映射与有边界的蒸汽粒子/阶段样式，可脱离 Pixi 实例单测。
- `src/game/systems/replay.ts`：输入意图回放策略，不修改模拟位置或强行开门。
- `src/game/systems/save.ts`：localStorage v1 存档。
- `public/assets/`：现有角色、场景和 UI 图片。`public/levels/` 内历史 JSON 不是当前加载源。

## 关卡编辑与回归

人物手感参数集中在 `src/game/engine/constants.ts`：`EMBER_SPEED` / `FROST_SPEED`、`MOVE_ACCEL` / `MOVE_BRAKE`、`JUMP_SPEED`、`ACTOR_GRAVITY` / `ACTOR_FALL_SPEED_MAX` 和 `LAND_RECOVERY_MS`。不要用全局时间缩放调跑速，也不要为了人物动作修改箱子的 `GRAVITY` / `FALL_SPEED_MAX`。调整跳跃速度时同时核对重力与五关回放，避免只降水平速度导致断口不可达。动作节奏和回归范围见 [操作手感与机关反馈](./操作手感与机关反馈.md) 与 [测试文档](./测试文档.md)。

1. 更新 [1–5 关玩法与布局](./1-5关玩法与布局.md) 的目标、路线或比例。
2. 修改对应 TS 关卡和必要的 `layout.ts`；新增字段先改 `sim/types.ts`。
3. 核对像素/格单位：`R` 的 x/w 按 48px 转换，y/h 另外乘 0.7；`branchLayout` 的坐标已经是最终格坐标，不再压缩。
4. 检查出生点支撑、跳高、顶棚净空、平台下穿、回程和关闭门能否被支路绕过。
   碎裂悬台只放入 `fragilePlatforms`，不可在 `solids` 重复保留；蒸汽标记/粒子必须与 `hazards` 范围一致。三星时间集中由 `finishRoom` 应用为 120/110/100/90/80 秒。
5. `npm test` 必须保留五关全收集输入回放与危险分支；`npm run build` 必须通过。
6. 启动页面，逐关检查加载、键位、暂停、重开、提示和至少一种小屏尺寸。自动回放不等于真人手感验收。

没有已实现的 F1 调试面板、`?level=` / `god` 深链或碰撞盒开关。检查模拟时优先编写测试；不要把调试用解锁/无敌入口发布给玩家。

## 当前限制

共享 Pixi/React 入口包仍触发 Vite >500kB 提示，本次未通过关闭告警或提高阈值掩盖。浏览器首次载入须等待关键图片，非关键动画失败保留 idle 帧并告警；关键图失败显示返回选关的错误页面。

本次没有修改路由、静态入口 HTML、域名、公开收录策略或第三方脚本，仅调整游戏 Canvas、选关与 HUD；SEO 属间接影响，未作线上抓取或 Core Web Vitals 结论。
