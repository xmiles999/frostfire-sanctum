# 接口文档

无 HTTP 业务 API。下列为模块契约与静态资源约定。

## 1. 输入动作

| action | 默认绑定 | 语义 |
|---|---|---|
| ember.left/right/up/down | A D W S | 水平与下蹲/下滑；up 为跳 |
| ember.interact | J | 点燃、拉杆、祭坛、放火种 |
| frost.left/right/up/down | 方向键 | 同上；冰面需点按 |
| frost.interact | `;` | 冻结浅水、熄火、卸负、祭坛 |
| pause | Escape | 开关暂停，停物理钟 |
| restart | R | 仅暂停菜单或死亡结算后立即有效；游玩中需长按 0.4s 防误触 |

同帧允许两套动作。`Intent.jump` 进入 100ms 缓冲。

## 2. 关卡 JSON 枚举

`hazard.type`：

`lava_shallow` `lava_deep` `water_shallow` `water_deep` `steam_hot` `ice_mist` `acid` `wisp` `laser` `impact_rune`

`puzzle.kind`：

`pressure_hold` `pressure_moment` `latch_door` `periodic_gate` `one_way` `lever` `gear_delay` `beam_source` `beam_mirror` `scale` `updraft` `combustible` `freeze_water` `phase_link` `swap` `fake_switch`

逻辑字段 `logic`：`and` `or` `xor` `nand`，输入为其它节点 id。

## 3. 运行时事件（Sim → UI）

| 事件 | 载荷 | UI |
|---|---|---|
| `actor.downed` | id, cause | HUD 救援倒计时 |
| `actor.revived` | id | 清倒计时 |
| `level.failed` | reason | 失败结算 |
| `level.cleared` | timeMs, deaths, stars | 通关结算 |
| `softlock.hint` | reason | 非打断提示 |
| `camera.separated` | distance | 失联条 |
| `puzzle.rejected` | nodeId | 只播音，不剧透 |

UI 不得写回物理状态，只能发 `pause` `resume` `restart` `intent`。

## 4. 存档读写

```
loadSave(): SaveV1
writeSave(partial: DeepPartial<SaveV1>): void
exportSave(): Blob  // application/json
importSave(text: string): { ok: true } | { ok: false, error: string }
```

`importSave` 失败不得覆盖现档。

## 5. 静态路径

| 路径 | 说明 |
|---|---|
| `/` | React SPA |
| `/levels/01.json` … `/levels/18.json` | 关卡 |
| `/assets/characters/ember/*` | 烬动画帧 |
| `/assets/characters/frost/*` | 朔动画帧 |
| `/healthz` | Caddy 直接 `ok`，不进 SPA |

## 6. 解法回放（测试）

```
ReplayStep { tMs: number, ember: Intent, frost: Intent }
```

`systems/replay` 在无 Pixi 下灌入 Sim。第 1、2、5 关必须有官方回放文件（阶段 C/D 落地）。
