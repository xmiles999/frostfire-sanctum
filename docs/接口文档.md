# 接口文档

更新：2026-09-22。无 HTTP 业务 API，本文仅记录当前模块契约。数据字段见 [数据模型](./数据模型.md)。

## 输入与运行时

`InputMap.pair(): PairIntent` 返回 ember/frost 两套 `Intent`：left、right、up、down、interact、jump。默认烬 WASD + J，朔方向键 + 分号；up 同时映射 jump，down 启用半速精准移动。`clear()` 清空按键集合。

`GameRuntime` 提供 `load(id)`、`restart()`、`pause()`、`resume()`、`attach(view)`、`detach()`。暂停保存之前的 playing / rescue_window 状态并清键，继续还原。UI 不直接修改角色坐标或门状态。

`onHud?: (hud: HudModel) => void` 最多 10Hz 发送完整 HUD 快照，包括 timeMs、deaths、steamPhase、doorOpen、doorPhase、latchMs、plateEmber/Frost、rescueMs、status、separated、stars、title、puzzleHint、levelId、restartHeldMs。

新增 `gems: { ember, frost, total, collected, runes }`：两人各自已取数量、总数量、已取总数、必需符文已取数量。没有额外事件总线或 WebSocket。

`guidance: { objective, mechanism, detail }` 为只读的下一步目标、机关状态/倒计时和补充说明；由 `roomGuidance(sim)` 从当前模拟状态派生，不自行推进时间、不改变物理或开门条件。

`actions: {ember, frost}` 来自 `interactionLabel(sim, who)`，显示附近可操作对象或对应角色的危险区通行说明；`feedback: string` 为当前短确认文案，无确认时为空。动态倒计时不放入读屏 live region，只有确认文案礼貌播报。

## 模拟与查询

- `createSim(level: LevelDocument): SimState`：创建全新单局。
- `stepSim(sim, intents, dt=1/120): void`：推进位置、收集、机关、危险、门与结算。
- `starsFor(sim): 1 | 2 | 3`：读取当前评分；三星要求全部收集物。
- `solidsNow(sim): Rect[]`、`activeHazards(sim): Hazard[]`：物理真相。
- `runesReady(sim): boolean`：全部必需收集物已取。
- `roomGuidance(sim): RoomGuidance`：根据收集、位置、潮位、烧桥、相位、齿轮和救援状态生成显示文案，优先提示救援/结算。
- `standingOnPlate(actor, plate): boolean`：站立脚心判定。
- `holdGateOpen(sim, gate)`、`gearWindowOpen(sim, window)`：包括防夹等待的开门判定，供渲染和碰撞复用。
- `officialPolicy(sim): PairIntent`：测试输入策略；只产生按键，不代改模拟状态。
- `stepFragilePlatforms(sim, dtMs)`：推进碎裂与恢复，恢复前检查角色/箱子占用。
- `nearInteraction(actor, rect, pad=18)` / `canIgnite(actor, bridge)`：交互范围共用判定，倒地者拒绝操作。
- `updateActorAnimation(actor, dt)`：根据运动/推箱/交互/倒地状态切换动作及局部时钟，不修改碰撞体位置。

## 资源和视图

`GameView.create(canvas, parent, signal?): Promise<GameView>` 先加载关键贴图，再建 Pixi Application，禁用自启动 ticker，统一由 GameRuntime 驱动绘制。关键资源失败由 UI 展示错误；非关键动画失败保留 idle 帧。`render(sim, dt)` 更新显示，`resetWorld()` 回收旧场景节点，`destroy()` 释放实例。共享纹理不在重开时销毁。

`actorPose(actor, reducedMotion)` 派生素材组、帧、循环策略、缩放和角度。`steamParticles(rect, phase, timeMs)` 派生范围内的少量粒子；`STEAM_STYLE` 提供三个阶段的文字/配色/粒子预算。视图不根据透明度反推伤害，危险区标签复用且只在阶段变化时更新文字。

浏览器路径：`/` 为 React 单页应用；`/assets/characters/`、`/assets/levels/01/`、`/assets/ui/` 为已有美术。选关以 React 状态切换，无新增关卡 URL。历史 `/levels/*.json` 不作为关卡加载 API。Caddy 部署提供 `/healthz`，不是开发服务器业务接口。

## 存档

`loadSave(): SaveV1`、`writeSave(next: SaveV1): void`、`recordClear(levelId, stars, timeMs, deaths): SaveV1`。没有当前可用的 importSave / exportSave 接口。失败边界见 [数据模型](./数据模型.md)。
