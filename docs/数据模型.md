# 数据模型

更新：2026-09-22。类型真相为 `src/game/sim/types.ts` 与 `src/game/systems/save.ts`；实现者新增字段时维护本文。旧版 JSON schema 是规划，不是当前运行时校验。

## 关卡 LevelDocument

关卡由 `src/game/levels/catalog.ts` 引用五份 TypeScript 数据。`tile=48`，`size={w:24,h:14}`；所有 Rect 均为世界像素 `{x,y,w,h}`，出生点是碰撞盒左上角。

| 字段 | 语义 |
|---|---|
| id / title / tile / size | 标识、名称和房间尺寸 |
| spawns / exits | ember、frost 的出生点与出口矩形 |
| solids / gatedSolids / hazards | 静态地形、终点闩门、危险区 |
| plates / holdGates | 终点双板、指定角色压住才开的接应门 |
| altar / wispNest / chargeBudget | 祭坛、残烬巢（负坐标禁用）、本关电荷 |
| score | starTimeMs 与 starDeaths |
| puzzle | dual_plates / tide / burn / phase / gear |
| crates / levers / tide | 箱子、拨杆、各潮位固体/水域/井板 |
| bridges / phaseGates / oneWays / extraPlates | 可燃桥、反相门、单向阻挡、相位板 |
| gear | windows 数组和可选 cycleMs；第五关为 10000ms 循环 |
| doorLatchMs | 覆盖默认开闩时长 |
| collectibles | 新增分色收集物列表 |
| fragilePlatforms | `{id, rect, crumbleMs, respawnMs}`；第三/四关可恢复碎裂悬台，不同时放进静态 solids |

收集物格式：`{ id: string, who: "ember" | "frost", rect: Rect, required?: boolean }`。每关 ID 唯一；`required=true` 为必需符文。普通晶石和符文均计入 6 件全收集目标。`gear.windows` 每项为 `{id, openAtMs, closeAtMs, solidsWhenClosed}`，时间相对该周期开始。

`layout.ts` 的 `R` 保留旧关卡作者纵向格坐标并乘 0.7 转换；`finishRoom` 移除旧底层长顶棚、增加支路、收集物和防绕门高度。`branchLayout` 返回最终世界格坐标，不使用第二次缩放。

## 单局 SimState

维护角色位置/速度/接地/跳跃缓冲/动画、模拟时间、状态、门阶段、双板时长、救援、箱子、桥、潮位、相位与齿轮时间等。

新增 `collected: string[]` 保存已拾取 ID。`createSim()` 初始化为空；拾取先核验角色颜色、存活与重叠，再去重添加。重开创建新实例，全部复原。`runesReady()` 检查所有必需 ID。

齿轮 `gearArmedMs=null` 表示未启动，有 `cycleMs` 时每步取模。第五关不存在超过一期后永久错过的闸口。收集进度与齿轮相位不写入存档。

- `fragilePlatforms: {id, phase, remainingMs}[]`：phase 为 stable / cracking / gone；支撑倒计时和恢复时间使用模拟毫秒。
- `phasePlateLatched: Record<string, boolean>`：标记本次踩住是否已切换相位，离板清除；不是跨局存档。
- `feedback: {text, remainingMs} | null`：最近一次操作确认，默认 1800ms。暂停冻结，重开清空，不是事件历史。
- 角色新增 `moveDir`（-1/0/1）、`pushing`、`interactMs`、`landImpact`，用于动作及操作提示；碰撞判定仍以位置/速度/实体为准。`ActorAnim` 包括 brake / push，`animTime` 是当前动作的局部时钟，走路/推箱按速度调整推进率。

## 持久化 SaveV1

localStorage 键：`frostfire.sanctum.v1`。

```json
{
  "version": 1,
  "settings": { "masterVolume": 0.8, "reduceParticles": false },
  "progress": {
    "unlockedCount": 1,
    "levels": {
      "01": { "cleared": true, "stars": 3, "bestTimeMs": 42000, "deaths": 0 }
    }
  }
}
```

示例仅说明结构，不是实测成绩。每次通关更新最高星数、最短时间与本次死亡数；解锁计数最多 18，UI 当前只展示已实现的五关。旧存档无需迁移，旧最高星数不因新全收集评分下降。

缺档、JSON 解析失败或版本不匹配使用默认档；没有已实现的导入/导出、坏档备份和嵌套字段完整校验。`writeSave` 直接写入整个 SaveV1，浏览器拒绝写入仍是限制。settings 字段尚无设置 UI，不意味着有声音播放系统。
