# 数据模型

所有持久化与关卡数据为 JSON。运行时对象不得成为存档真相。schema 用 zod 在加载时校验（阶段 B 落地代码）。

## 1. 存档 `frostfire.sanctum.v1`

```json
{
  "version": 1,
  "exportedAt": "2026-09-17T00:00:00.000Z",
  "settings": {
    "masterVolume": 0.8,
    "sfxVolume": 1,
    "musicVolume": 0.7,
    "shake": true,
    "reduceParticles": false,
    "reduceFlash": false,
    "bindings": {
      "ember.left": "KeyA",
      "ember.right": "KeyD",
      "ember.up": "KeyW",
      "ember.down": "KeyS",
      "ember.interact": "KeyJ",
      "frost.left": "ArrowLeft",
      "frost.right": "ArrowRight",
      "frost.up": "ArrowUp",
      "frost.down": "ArrowDown",
      "frost.interact": "Semicolon",
      "pause": "Escape",
      "restart": "KeyR"
    }
  },
  "progress": {
    "unlockedCount": 1,
    "levels": {
      "01": {
        "cleared": true,
        "stars": 2,
        "bestTimeMs": 188000,
        "deaths": 4,
        "rescues": 0,
        "chargeUsed": false
      }
    }
  }
}
```

规则：

- `unlockedCount` 为已解锁关序号最大值；通关第 n 关后至少 `n+1`（上限 18）
- 未出现的关 id 视为未打
- `stars` 只升不降
- `bestTimeMs` 取最小
- 损坏时复制到 `frostfire.sanctum.v1.bak` 再回退默认

## 2. 关卡文档 `public/levels/XX.json`

```json
{
  "id": "01",
  "title": "裂隙初醒",
  "tile": 48,
  "size": { "w": 48, "h": 16 },
  "parallax": ["bg-far", "bg-mid", "fg"],
  "spawns": {
    "ember": { "x": 2, "y": 4 },
    "frost": { "x": 2, "y": 13 }
  },
  "exits": {
    "ember": { "x": 46, "y": 4, "kind": "hearth" },
    "frost": { "x": 46, "y": 13, "kind": "cistern" }
  },
  "solids": [],
  "platforms": [],
  "hazards": [],
  "actors": [],
  "puzzles": [],
  "altars": [{ "x": 38, "y": 10, "chargeCost": 1 }],
  "checkpoints": [],
  "score": { "starTimeMs": 240000, "starDeaths": 6 },
  "chargeBudget": 1
}
```

`solids`：轴对齐矩形列表，世界像素。  
`hazards[]`：`{ id, type, rect, params }`，`type` 枚举见接口文档。  
运行时关卡对象另有可选 `puzzle`（`dual_plates` / `tide` / `burn` / `phase` / `gear`）、`crates`、`levers`、`tide`、`bridges`、`phaseGates`、`oneWays`、`extraPlates`、`gear`。第 1–5 关以 TypeScript 模块提供，尚未拆成独立 JSON。

坐标原点左上，y 向下，与 Pixi 一致。

## 3. 机关运行时（不持久化）

```
PuzzleNode {
  id: string
  kind: pressure | latchDoor | periodic | gearDelay | beam | lever | ...
  powered: boolean
  phaseMs: number
  latchRemainingMs: number
}
```

关卡重开时丢弃运行时，从 JSON 重建。

## 4. 模拟快照（供渲染与测试）

```
SimSnapshot {
  frame: number
  actors: { id, pos, vel, state, downed, elementWet, elementBurn }
  hazardsActive: string[]
  puzzles: Record<id, PuzzleNode>
  rescue: null | { downedId, remainMs }
  chargeLeft: number
  status: playing | rescue_window | failed | cleared
}
```

## 5. 版本迁移

`version` 只增。v1 无迁移。以后加字段必须给默认值，禁止改语义而不改 version。
