# 测试文档

## 1. 策略

逻辑与渲染分离。CI 与本地以 vitest 跑 Sim。不强制 e2e 打开浏览器（Plan 阶段无页面）。阶段 E 可用 Playwright 抽检菜单与第 1 关加载。

## 2. 必须自动化（按阶段）

### 阶段 B（已落地，`npm test`）

- 元素伤害矩阵：水/熔岩/冰雾/蒸汽 telegraph 与 lethal
- 寻热残烬：最近目标、烬安全、朔倒地、丢失回巢
- 双压板：单板不开门；同时 0.80s 后闩 5.00s（离开压板后倒计时关闭）
- 跳跃：长按落地不自动连跳；松键短跳低于持续按住；落地前按键可进入 100ms 跳跃缓冲
- 闩锁门：开启、保持、0.45s 闭合完整状态变化；门洞有人时延后闭合
- 终点：单人进槽不清关
- 第 1 关官方解法回放通关（0 死、电荷仍在），且「朔先冲残烬廊」回放失败
- 第 1 关烬不跳第一坑倒地（冰雾井/水）；朔不跳熔岩渗带倒地；烬不踩第一块按住板则朔过不了石门
- 残烬丢失目标后回到 idle，位置仍在巢的巡逻幅度内
- 第 2–5 关官方解法回放 0 死通关
- 第 2 关深潮位淹没烬的低路；走进潮位拨杆不按交互也会换档；第 4 关朔不诱敌先冲内环则倒地

### 阶段 C

- 存档读写、损坏备份、导入失败不覆盖
- 键位重绑后 Intent 映射
- 救援 8s 超时失败、祭坛扣电荷、复活无敌 1.2s
- 相机失联减速但不传送
- 可燃桥分段坍塌落点
- 水位三档与箱密度

### 阶段 D

- 关卡 01–18 JSON 通过 schema
- 至少第 1、2、5、11、18 关官方回放通关
- 第 9 关假开关导致对应喷口
- 第 18 关无未声明的 `puzzle.kind`

## 3. 手工验收

| 项 | 方法 | 通过 |
|---|---|---|
| 第 1 关难度 | 未读文档试玩 | 不能 30s 无脑过；死因可理解 |
| 写实观感 | 1080p 截图 | 不是方块人/像素瓦片人 |
| 双人同机 | 两套键 | 第 1、2、5 关可过 |
| 单人双手 | 一人 | 同上 |
| 暂停重开重绑 | 关卡 HUD 按钮与 Esc / R | 返回回选关；暂停停物理；游玩中长按 R 0.4s 重开 |
| 跳跃手感 | 起跳后分别轻点/长按；从台沿晚按；落地前早按 | 短跳明显更低，土狼时间与缓冲可感知，无长按自动连跳 |
| 蒸汽/盖板 | 连看两个周期 | 安全、预示、喷发三态区别明确；预示不少于 0.4s |
| 双压板/门 | 单踩、双踩、开门后离板、站门洞等候闭合 | 侧擦不触发；压板下沉与符文进度同步；门不夹角色 |
| 2–5 关造型读解 | 不看文案试玩 | 场内无操作句；铜菱/箭头/管路/沉钟能对上机关；HUD 只报潮位/燃烧/闸/轴 |
| 刷新恢复 | localStorage | 选关星数仍在 |
| 低粒子 | 设置 | 判定不变 |

## 4. 第 1 关回放断言（规划）

回放脚本按 [关卡设计.md](./关卡设计.md) 官方 6 步生成时间轴。断言：

- `status === cleared`
- `deaths === 0`
- `chargeLeft === 1`
- 全程朔未停留在 `lava_*` 致死带，烬未进入 `water_*` / `gap_mist`

失败回放：朔在残烬 `idle` 于廊中时进入廊中心 → `frost.downed`。

## 5. 未覆盖风险

- 手感（缓冲是否「好用」）只能试玩
- 美术一致性不能单测
- 蒸汽密度、盖板震颤幅度、压板下沉量、门扇运动、岩浆气泡与河面焦散仍需真实浏览器截图和试玩判断
- Dokploy 网络与证书在仓库内不能测，只测镜像 healthz（阶段 E）
